Music Lab

Music Lab is an interactive music analytics platform built using a Spotify tracks dataset. It combines data analysis, a recommendation system, and a web interface to explore music in a more interactive way.

How I Built It

I started by cleaning and analysing the Spotify dataset using Pandas, NumPy, Matplotlib and Seaborn. I explored features such as energy, danceability, valence, acousticness and popularity to identify patterns in the data.

I then built a data-driven recommendation system that compares the musical characteristics of songs and generates similarity-based recommendations.

For the backend, I used Flask to create APIs that handle recommendations, Music DNA, mood discovery, hidden gems, genre analysis and song comparisons.

The frontend was built using HTML, CSS and JavaScript, with the JavaScript frontend communicating with the Flask backend through APIs.

Tech Stack

Python, Pandas, NumPy, Matplotlib, Seaborn, Flask, Flask-CORS, HTML, CSS and JavaScript.

What I Learned

This was my first Python project and gave me hands-on experience with data cleaning, exploratory data analysis, recommendation logic, API development and connecting a Python backend with a web frontend.

The project also helped me understand how different technologies can come together to turn raw data into a complete interactive application.

Future Improvements

I plan to explore Spotify API integration, more advanced recommendation algorithms, personalised recommendations and machine-learning-based approaches in future versions.
